# 开发日志与决策记录

## 当前项目状态
- 项目：Godot 2D 俯视角修仙增量动作游戏（Godot 4.5.1）。
- 当前阶段：M1 最小可玩闭环代码已完成（阶段 1–6 全部落地），完整循环待手动实测确认。
- 当前目标：建立最小可玩闭环（修炼区 → 副本 → 结算 → 成长 → 再进入）。

## 已确认决策
1. 战斗为主动操作型：玩家控制移动、普攻和主动技能。
2. WASD 移动；J 普攻；K、L、U、I、O 为主动技能键。
3. 朝向使用最后方向记忆；技能默认沿角色当前朝向释放，不默认采用鼠标瞄准。
4. J 普攻不消耗法力；主动技能消耗法力且有独立冷却。
5. 主动技能施放需满足已解锁、冷却结束、法力充足；校验失败不扣蓝、不启动冷却、不执行技能。
6. 法力持续自动恢复，战斗、移动与施放期间都恢复；法力耗尽仍可移动和普攻。
7. 每次进入副本时法力回满。
8. 技能键固定，不采用自由装备技能系统；技能随境界逐步解锁。
9. 副本临时收益与永久资源分离；成功撤离带走全部收益。
10. 必须抵达固定出口才能撤离；出口始终可用，不要求清空敌人；第一版不做复杂撤离读条或道具。
11. 死亡结束本次副本；第一版不做复活点、尸体回收或复活道具。
12. 失败保留部分普通资源；原型建议修为与灵石保留 50%，需测试调整。
13. 普通敌人可有限刷新；精英和首领不刷新；重刷敌人不重复提供常规资源。
14. 第一版优先实现一个代表性流派的垂直切片，不同时制作所有流派。
15. 死亡短暂失败演出可后续添加，不作为当前闭环的前置条件。
16. **第一版灵根/法宝已确认：火灵根 + 刀类法宝。**
17. **境界名称已确认：练气 → 筑基 → 金丹 → 元婴。**
18. 场景结构：修炼区 Hub + 副本 Dungeon 两个场景，用 `change_scene_to_file` 切换。
19. 单局状态由新增 autoload `RunManager` 管理（临时收益 + 结算防重复）。
20. 成长链：灵石购买丹药 → 服用 → 属性永久提升；丹药为独立永久资源。
21. M1 只做 1 种「淬体丹」（提升攻击）；丹药定义集中 `data/`，未来加丹药 = 加一条配置。
22. M1 暂缓 B 突破（突破境界后续重做，M1 只保留丹药一条成长线）。
23. M1 修炼区按键：E 进副本、B 购买丹药、C 服用丹药（突破暂缓，B 键让给购买）。

## 原型参数（需要测试）
- 法力上限 100。
- 法力自动恢复 5 点/秒。
- 主动技能消耗示例：K 20、L 30、U 40、I 25、O 50。
