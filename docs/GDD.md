# 游戏设计文档（GDD）

## 一句话
俯视角修仙动作游戏：选灵根功法 → 进副本打怪采集 → 突破境界变强 → 挑战更难副本。

## 核心循环
进副本 → 击杀妖兽 → 掉落灵石/材料 → 采集 → 攒够资源 → 突破境界 → 属性提升 → 挑战更难副本/新副本

（无挂机收益：所有资源都要主动打怪获得）

## 灵根 & 功法（影响科技树 + 战斗表现）
- 灵根属性：火 / 水 / 木 / 金 / 土（后续扩展）
- 功法：刀 / 剑 / 法杖 等（后续扩展）
- 不同组合 → 不同科技树、不同战斗表现

### 当前 MVP：火 + 刀
- 操作：WASD 移动 + 鼠标瞄准/左键攻击（手动瞄准，哈迪斯式）
- 战斗表现：近战刀气，火属性灼烧
- 科技树：火系/刀系加成（后续）

## 境界
练气 → 筑基 → 金丹 → 元婴

每突破一次：攻击/血量提升，解锁新副本。

## 资源（名称占位，随时可改，集中在 data/）
- 灵石：通用货币，突破消耗
- 突破材料：副本掉落（后续可细分）

## 系统规划（按优先级，先做前 4 个）
1. 玩家移动 + 刀攻击（火）
2. 敌人 + AI + 副本
3. 掉落 + 采集
4. 突破境界
5. 开局选灵根/功法界面
6. 科技树
7. 更多属性/功法

## 数值公式（初版占位，后续平衡）
突破所需灵石 = 基础值 × 2^(境界序号)
