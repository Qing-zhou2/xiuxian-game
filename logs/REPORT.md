# 项目阶段报告

> 快照时间：2026-10-12。本文件描述「当前开发阶段 + 已实现内容」，随每次会话更新。

## 一句话概况
Godot 2D 俯视角修仙动作游戏，MVP 流派「火灵根 + 刀类法宝」。当前处于 **M1 最小可玩闭环** 收尾阶段：代码已全部落地，待手动实测验收。

## 技术栈
- 引擎：Godot 4.5.1
- 语言：GDScript
- 平台：Windows 桌面

## 已完成（M1 六阶段全部落地）
1. `data/` 配置层 — 数值/名称/丹药集中配置（`data/game_config.gd`），铁律 #1。
2. 场景骨架 — 修炼区 Hub + 副本 Dungeon，`change_scene_to_file` 切换。
3. 单局状态 — `RunManager` autoload，临时/永久资源分离 + 统一结算（防重复、失败保留 50% 下取整）。
4. 副本内容 — 出生点、敌人（含接触伤害）、拾取、固定出口、死亡结算。
5. 成长选项 — 淬体丹（灵石买 → 服用 → 攻击永久 +5）。
6. 收尾 — 结算结果反馈、买/服失败提示、防重复领取。

## 核心玩法闭环（已实现）
修炼区（买丹/服丹）→ 进副本 → 战斗/拾取 → 撤离（全额）/死亡（保留 50%）→ 结算入账 → 成长 → 再进。

## 目录与模块
- `scenes/`：Hub.tscn（修炼区）、Dungeon.tscn（副本）
- `scripts/`：Player（移动/普攻/朝向记忆）、Enemy（追击/接触伤害）、Slash（刀气）、Drop（掉落）、Hub、Dungeon、GameManager（永久资源）、RunManager（单局状态）
- `data/`：game_config.gd（数值/名称/丹药配置）
- `assets/`：贴图素材
- `docs/`：设计/技术/路线图/决策记录
- `logs/`：每次开发会话日志（本文件夹）
